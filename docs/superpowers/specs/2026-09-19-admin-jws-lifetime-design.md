# 管理员用户列表 JWS 生命周期展示设计

## 目标

管理员用户列表不再只根据 `jws` 字段显示“有效/失效”，而是直接展示每个用户的 JWS 创建（最近刷新）时间和按 28 天有效期计算的剩余时间，并通过颜色帮助管理员快速识别即将到期或已经过期的账号。

## 数据来源

- 继续使用管理员用户分页接口已经返回的 `jwsRefreshedAt`。
- `jwsRefreshedAt` 视为当前 JWS 的创建或最近续签时间。
- 有效期基准与用户首页保持一致，为 28 天。
- 本功能不新增数据库字段，不修改后端接口。

## 时间计算

前端根据以下规则计算状态：

1. 到期时间为 `jwsRefreshedAt + 28 天`。
2. 剩余时间为到期时间减去浏览器当前时间。
3. 未到期时显示完整天数和小时数，例如“剩余 12 天 6 小时”。
4. 不足一天时显示剩余小时；不足一小时时显示“剩余不足 1 小时”。
5. 已到期时显示过期时长，例如“已过期 2 天 3 小时”。
6. `jwsRefreshedAt` 为空或无法解析时显示“无创建记录”。

## 高亮规则

- 绿色：剩余时间超过 7 天。
- 黄色：剩余时间大于 3 天且不超过 7 天。
- 红色：剩余时间不超过 3 天、已经过期或没有可用创建时间。

颜色使用项目现有 Tailwind 色阶：`emerald`、`amber`、`rose`，不引入新的 UI 依赖。

## 页面展示

### 桌面列表

- 将现有“JWS”状态列改为“JWS 生命周期”。
- 每行第一行显示带高亮背景的剩余时间。
- 第二行显示创建时间，格式与列表现有日期格式一致。

### 移动端列表

- 将右上角“JWS 有效/失效”徽章替换为高亮的剩余时间。
- 在徽章下方补充简短的创建时间，保证移动端也能看到完整信息。

## 刷新行为

管理员执行“刷新 JWS”成功后，页面沿用现有逻辑重新加载用户列表。新的 `jwsRefreshedAt` 返回后，生命周期展示立即重新计算，无需增加额外请求。

## 异常处理

- 时间字段为空、格式错误或浏览器无法解析时统一按未知状态处理。
- 未知状态使用红色高亮并显示“无创建记录”，不再错误显示成“有效”。
- 计算逻辑不得依赖 `jws` 布尔值判断剩余时间，但现有筛选和统计接口暂不改动。

## 验证

- 运行 `npm run build` 验证 Vue 模板和生产构建。
- 人工检查无记录、正常、7 天内、3 天内和已过期五类计算结果。
- 不运行 Playwright。
