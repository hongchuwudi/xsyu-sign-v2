# XSYU Sign v1.1.0 用户更新设计

## 目标

发布 XSYU Sign v1.1.0，统一系统版本展示，发布一份只面向普通用户的更新公告，为公告页增加历史公告切换，并恢复“源码”标签中独立一键签到 Java 工具的在线查看与复制功能。

## 版本统一

- 前端 `package.json` 和 `package-lock.json` 版本更新为 `1.1.0`。
- 后端 Maven 项目版本更新为 `1.1.0`，Docker 构建同步使用新的 JAR 文件名。
- Vite 在构建时读取前端包版本并注入应用，“关于软件”页面不再硬编码版本号。
- 页面显示形式为 `版本 1.1.0`，公告适用版本填写 `1.1.0`。

## 历史公告切换

### 后端

- 新增普通用户接口 `GET /user/announcements`。
- 接口复用现有公告查询逻辑，按 `created_at` 倒序返回全部公告。
- 保留 `GET /user/announcement/latest`，避免破坏现有调用。
- 管理员增删改接口和资源关联逻辑不变。

### 前端

- 公告页首次加载公告列表，默认选择第一条，也就是最新公告。
- 公告标题区域增加小型“历史公告”按钮。
- 点击按钮后展开紧凑列表，展示公告标题、适用版本和发布日期。
- 最新公告显示“最新”标记，当前选中公告使用高亮背景。
- 选择历史公告后原地替换标题、时间和 Markdown 正文，不跳转路由。
- 点击页面其他区域、再次点击按钮或选择公告后关闭列表。
- 没有公告时继续显示现有空状态；加载失败时给出可重试提示。

## 一键签到源码恢复

- `xsyu-sign-web/public/code/XSYUOneKeySign.html` 和 `XSYUOneKeySign.txt` 已存在并会进入 Vite 构建产物。
- 当前故障原因是 `/code/**` 被 JWT 拦截，iframe 及其内部源码请求均返回 401。
- 在 JWT 和限流拦截器的静态资源排除路径中加入 `/code/**`。
- 源码本身是项目公开展示内容，因此允许通过公网地址直接访问。
- 保留现有 highlight.js 高亮和“复制代码”按钮，不重写静态工具。

## 用户更新公告

标题：`XSYU Sign v1.1.0 更新通知`

正文：

```markdown
# XSYU Sign v1.1.0 更新通知

你好，XSYU Sign 已更新至 v1.1.0。

## 本次更新

- 全面优化首页、公告、签到和个人中心页面。
- 首页新增 JWS 剩余时间展示，可以直接查看登录状态的创建时间、预计到期时间和剩余时长。
- 公告页面升级，支持更加清晰的 Markdown 排版和图片内容。
- 公告页面新增历史公告切换功能，可以查看不同版本的更新内容。
- 恢复一键签到工具源码页面，支持在线查看和复制 Java 源码。
- 优化学校账号密码登录提示，可以更准确地区分密码错误、验证码要求和账号锁定。
- 完善短信登录、扫码登录和学校密码更新流程。
- 优化自动签到、签到记录查询和页面加载体验。
- 修复部分情况下页面资源加载失败、登录状态异常等问题。
- 提升移动端页面适配效果和系统整体稳定性。

## 使用提示

JWS 登录状态通常按 28 天有效期计算。即将到期或已经过期时，请重新登录系统。

通过短信或扫码登录的用户，如果需要系统自动续期 JWS，请前往“我的”页面更新学校密码。

感谢你的使用与支持。
```

公告不得包含 CI/CD、服务器、数据库、OSS、管理员后台或其他内部实现细节。

## 发布流程

1. 完成代码修改并运行前端构建、后端打包。
2. 提交相关文件，不包含工作区已有的无关修改。
3. 推送 `main`，等待 GitHub Actions 构建 v1.1.0 镜像。
4. 手动触发生产部署并通过健康检查。
5. 部署成功后在生产数据库插入 v1.1.0 公告，避免用户在新版上线前看到更新通知。
6. 验证首页、历史公告切换、关于页版本和 `/code/XSYUOneKeySign.html`。

## 验证

- `npm run build` 成功。
- `mvn package -DskipTests` 成功。
- `/code/XSYUOneKeySign.html` 和同目录 TXT 在线返回 200。
- 公告页默认显示最新公告，可以切换历史公告并返回最新公告。
- “关于软件”显示版本 1.1.0。
- 不运行 Playwright。
